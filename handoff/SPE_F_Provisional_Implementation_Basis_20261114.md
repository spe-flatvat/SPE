## 1. 目的と位置付け

本書は、第二次Milestone宣言に基づくF施策の損税解消モデル開発に必要な、Fの標準実施経路を暫定的に特定する。政策原本の改訂やRPの新設を目的としない。

Ownerが本書を限定承認した場合、本書は対象の試作・検証における実装根拠となる。`policies/FreedomPolicies.md` および `policies/FreedomPolicies_Annex.md` は変更せず、既存原案は参考・比較用に維持する。本書は正式な政策原本・Canonical文書を置き換えない。

## 2. F標準実施経路（Owner方針）

1. **政治調整版の実施経路をFの標準として採用する。** 従来原案は参考・比較対象として残す。
2. 消費税改革は**5%への減税を先行**し、医療・教育・土地・不動産等への**課税ベース拡大を後続段階**で実施する。
3. **課税ベース拡大の完了目標年は2038年**とする。従来原案の「2035年頃の完全フラット化」は標準実施経路の完了年としては用いない。
4. 到達目標は**消費税5%の広い課税ベースによるフラット化**であり、**金融取引は対象外**とする。金融サービスの個別取扱いなど未確定の制度細目は本書で新規裁定しない。
5. 社会保障経由の低・中所得層への還元、移行支援など、既存F施策の政策目的・制度要素は、本書で明示的に変更しない。

## 3. 年次実装上の取扱い

- 2026〜2055年の年次計算を対象とし、まずF／StatusQuoを同じ初期条件・イベント条件で比較する。N3は優先拡張、N・F3・R4は将来拡張とする。
- **減税の具体的な施行年、2038年までの中間税率、部門別課税開始年・対象範囲、移行支援額は本書だけでは確定しない。** 既存資料で確認できない数値をOwner決定値として補完しない。
- 未確定値は、試作時に明示した暫定入力パラメータとして変更可能にする。暫定値の採用は政策原本の確定を意味しない。
- 損税解消の発生時期は、各部門の課税・仕入税額控除の適用開始時期に応じて計算する。2038年に効果を一括計上することも、減税開始年に全額を先取りすることも、制度条件なしには行わない。

## 4. 損税解消の計算原則

- **損税循環の数理モデルは未実装であり、計算はこれからである。** 既存F試算の成長・税収効果を損税解消から導出済みとは扱わない。
- 最小試作は医療・教育・不動産賃貸の3部門を対象とし、制度変更前後の控除不能消費税相当額を年次で区別して算出する。
- 損税額の減少を、そのままGDP増加、税収純増、事業者純利益または家計便益と同一視しない。価格・税収・事業者・家計・公的支出への帰着は区分して扱う。
- F別紙2の**年間約1.7〜2.55兆円**は従来の概算規模であり、モデルの正解値・保証値・自動入力値にはしない。
- 既存の税収弾性値（1.5→1.7→2.0等の試算上の経路）は損税解消から導かれたものではない。初期段階では既存マクロ効果と新規損税診断を別表示し、二重計上を避ける。
- 先行減税と課税ベース拡大の時間差による財政収支・国債発行の変化は計算対象とするが、**税収回収の早期化自体を政策の成功条件とはしない。** 物価、実体経済、分配、供給力、財政制約等を併せて比較する。
- F別紙6-Gにある追加国債発行累積約120兆円等は従来の暫定試算として参照できるが、新モデルの計算結果として固定しない。
