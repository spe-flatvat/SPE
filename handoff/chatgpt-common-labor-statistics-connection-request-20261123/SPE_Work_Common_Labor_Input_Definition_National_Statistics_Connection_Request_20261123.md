## 3. Stage A：統計原典・定義・実装の対応を確定

1. 内閣府SNAの実質付加価値・名目GDP・就業者・総労働時間（取得可能な系列）、総務省労働力調査の就業者・従業時間・年齢×性別就業率、総務省人口推計、社人研将来推計人口、必要に応じ厚労省外国人雇用届出・在留統計について、**原典表・表番号/系列ID・公表日/対象年・基準年・対象母集団・単位・季節調整・暦年/年度・年平均/10月時点**を実際に確認する。原典にアクセス不能な場合は利用可能な既存取得原本と区別し、未取得を明記。外部統計の数値を推測して埋めない。
2. 「15歳以上人口」「労働力人口」「就業者」「雇用者」「延べ労働時間」「FTE（定義した基準年間時間による換算）」「有効労働L」「1人当たり付加価値」「時間当たり実質付加価値」「TFP」「資本サービス」を別変数として整理。就業率の分母、外国人常住者/雇用届出者/在留者の範囲、2025実績→2026条件付き人口の橋渡しを明示。
3. 実際に現行SQのLへ入力される年齢・性別・国籍別人数と就業率、Fの高齢就労・外国人材・教育/医療/健康の追加労働、N3固定コアの読込箇所を追跡。就業者人数を時間・生産性・資本で既に調整したと誤認しない。2025全国就業者数差のうち時点/母集団/推計差で説明可能な部分だけを実証し、残差を残す。
4. SNAと労働力調査の系列が同年同母集団で接続できない場合、無理な除算・スケーリングをしない。**同定義接続可／条件付きproxy／N/A**を列ごとに分類。

## 4. Stage B：隔離した労働投入ブリッジの実装と2026–2055年次実行

既存SQを`BASE_SQ_UNCHANGED`として実コード再実行し、以下を最小限の独立した診断枝として実装する。現行本線には混入しない。

- **人数ブリッジ**：2025年齢×性別就業者数・国籍別常住人口と2026初期条件を、同一時点/定義で整合できる範囲まで接続。年次就業者数、人数ベースL、L/L0、実質コア・最終GDPを再計算。全国人数の一様倍率はL/L0で相殺されるため、見かけのGDP改善として扱わない。
- **労働時間ブリッジ**：取得した実際の労働時間統計から、年間時間・総時間・定義済みFTEを算出。年齢/性別/国籍別時間が取得できなければ、全国平均の一定時間を仮置きした**診断対照**と、根拠ある集計感度を分離。2026〜2055将来時間は外部予測がなければ固定仮定とし、政策値として採用しない。時間データがない場合は人数・時間ブリッジの可能な部分を実行し、FTEはN/Aとする。
- **付加価値・生産性ブリッジ**：同年・同基準のSNA実質付加価値/時間または/就業者の実績系列が取得できる場合、基準年の単位整合と過去実績の比較を実行。将来のTFP上昇や資本代替は自動推定しない。明示的な生産性系列を新設する場合は`A`の既存1%成長/リスク蓄積と二重計上しない対照枝を設け、未採用の条件付き感度とする。
- **二重計上・基準年検査**：Fの政策追加労働とSQ既存高齢就業、外国人材、健康による追加労働の重複、L基準年の取り直し、人数×時間×生産性の単位と名目/実質の混同を機械検証。

全枝は初期2026実質580/名目600、29遷移、共通価格・イベント・医療参照・SQ人口定義を固定。統計接続のために人口・移民・労働弾性0.65・基調成長1%・災害回復を無承認変更しない。未取得データがあるときは、成立する枝を先に実行して、成立しない枝をN/Aで残す。

## 5. Stage C：差分・F/N3波及と採用候補の識別

1. 2026/2030/2035/2039/2055および全30年について、現行SQ、統計定義整合の人数枝、時間/FTE枝、実績生産性接続枝（実行可能なもの）の**人数・総時間・FTE・実質GDP・SQ差**を表示。年次の水準差と基準年/構成変化を分離。時間・付加価値・資本が未取得なら0とせずN/A。
2. SQの人口規模・年齢/性別構成・国籍構成・就業率・時間・生産性の寄与を、同定義で識別できる範囲で分解し、相互作用・残差を開示。既存Shapley 5要因を再利用し、異なる条件の分解を直接足さない。
3. FとN3について共通労働ブリッジが読まれるコード依存、必要な基底再構築、二重計上リスク、同条件で可能な最小対照を示す。**同条件で再計算できる場合は実行**し、できない場合はN3最終GDPを創作しない。全面的なF/N3モデル再設計は今回の完了条件ではない。
4. 改善候補を`DATA_DEFINITION_ALIGNMENT`、`CALIBRATION_CANDIDATE`、`STRUCTURAL_MODEL_CHOICE`、`POLICY_SPEC_REQUIRED`、`NOT_IDENTIFIABLE`に分類。全国統計に合わせた単純倍率調整を「改善」と称さず、旧版との比較で**新たに何を実計算できたか**を明示。
