## 1. 目的・今回新たに解く問い

直近のSQ/F/N3共通条件再計算とClaude独立検算を再利用し、SQ実質GDPが2026年580兆円から2055年528.962336兆円へ下がる**人口→労働投入→実質コア→最終GDP**の計算経路を、実コード・入力原本・年次中間値・限定反実仮想で特定する。労働弾性0.65、人口と有効生産労働者の接続、就業率・年齢/性別/国籍・労働時間・生産性・資本代替の未接続部分を切り分ける。

**目的はGDPの数値合わせではない。** 人口減少の実測/条件付き推計と、就業者・有効労働・時間・付加価値/労働生産性を同一概念として扱わない。実装が持つ項と持たない項を区別し、未較正の全国値を発明しない。SQは共通ベースラインとして保持し、F/N3に波及する技術候補は隔離診断のみにする。

## 3. Stage A：現行SQの実コード・年次労働伝播の分解

1. 2026〜2055年の`population`、working_age、elderly、国内/外国人就業、`effective_productive_workers`（L）、L/L2026、労働弾性0.65、非労働係数A、コア実質GDP、最終実質GDP、需要/供給/価格圧力を、**実際に読まれたコードと入力**から出力。コードで使われない研究用列は`NOT_CONNECTED`と明示。Lが就業人数・就業時間・質調整・人口比例のどれを意味するか定義を確定。
2. `Ycore=580×A×(L/L2026)^0.65`の年次算術を独立再計算。Aを基調成長・各リスク損失の水準累積へ、Lを人口規模・年齢構成・就業率/参加率・外国人流入・換算生産性へ、**実装可能な限度で**分解。存在しない接続を分解済みと称さない。
3. 実質GDPの2026年580割れ初年、各年のコア/最終GDPの差、2030/2035/2039/2055、29年連続580割れの根拠を再現。人口・L・生産性・Aの差の積項/相互作用は明示し、単純寄与の足し算で閉じない場合は残差・順序依存性を記録。
4. 初期人口122,618,024と原文121,500,000の差、社人研基準、2026実績参照、外国人純移動の条件付き推計、2026基準年のL固定、Fの政策人口差を混同せず、根拠・未較正・実装選択を分類。
5. 生産性を`A`の基調成長/リスク合成と同義と断定しない。資本・TFP・労働生産性・時間当たり付加価値・人口1人当たりGDPのうち、現行モデルが何を明示的に計算しているか特定し、暗黙の残差と区別。

## 4. Stage B：最小限の隔離反実仮想

現行SQを不変の`BASE_SQ_REPLAY`として2026〜2055年再実行し、**労働接続の要因を識別できる最小のケース**を隔離コピーで実行。既存11/18人口研究と11/22 SQ成長診断の同条件PASSは再利用し、同じ感度を再実行する必要がある場合のみ理由を記録。

候補例（採用義務なし）：(a) Lを2026水準に固定してAだけ動かす、(b) Aを2026水準に固定してLだけ動かす、(c) 労働弾性0.65の条件付き上下感度、(d) 人口のみ変更・就業率固定、(e) 年齢構成・就業率接続を切り替え、(f) 明示された就業者1人当たり生産性の条件付き変更。**存在しないパラメータ・統計値を創作せず、実装済みコードと出典を確認して可能な枝のみ選択**。必要なら逐次分解と逆順分解の両方で相互作用を表示。これらは政策提案・正式人口予測ではなく、機械的な構造識別である。

各枝は初期580/600、共通イベント・物価・2026初期境界・SQ医療等の固定条件を保つ。Aの固定枝はイベント効果をOFFにする診断であることを明示。SQを上回るような係数の調整・災害デバフの恣意的な弱体化は禁止。
