## 実行と再現

先行13原本を取得し、先行保全記録が列挙する12原本はサイズとSHA-256を照合。先行6,273件PASSを再利用した。今回は4枝・120年次を別プロセスで2回実行し、新規 **8,650件PASS、失敗0**。二つの年次CSVと両系統の基礎年次・トレースが実バイト一致。実額の現預金、外部調達、全国完全PBは未推計。

先行コミットのディレクトリを `prior` に取得し、Runtime_Sources.json の各 `fixed_path` を指定 `ref` から取得して `runtime` の各 `path` に配置する。2026〜2055年の固定入力は Run.py がサイズ・SHA-256を確認する。Inputs.jsonの4枝それぞれを、独立プロセスで `python Run.py runtime prior runs/<枝> <枝>` と `python Run.py runtime prior replay/<枝> <枝>` で実行し、`python Compare.py prior runs replay exports` で集計する。出力先ディレクトリは事前に作成する。

本結果は非採用診断。旧F基準、政策本文・Annex、固定SQ・N3、main、DecisionLogの変更を伴わない。RP-023／M19–25 HOLD、RP-024 PENDINGおよび既存の承認ゲートを維持する。
