# Stage 2 教育・医療の連結増分資金勘定

固定Fの教育・医療事業の範囲で、歳入・歳出、利払い前収支、利払い、償還、金融資産取得、総発行、純発行、期首期末債務、未割当資金を同一勘定に接続した。f-education-20261121/Model.py の Education、FMedical.py の Medical.step、f-integrated-20261121/Model.py の fiscal を再利用。既存モデルが置く個別の利率・償還スケジュール以外の調達仮定を追加しなかった。

純歳入は医療の追加税・保険料から教育訓練控除を控除。純歳出は再配分後教育支出と、医療の税・保険料増分前の政府・保険者の連結純費用から既存支出振替を引いた額。奨学金・移行支援等の移転を支出に含める部分現金勘定で、実物支出のGDP項目として再加算しない。PB＝純歳入−純歳出、資金所要＝利払い−PB＋償還＋資産取得、未割当＝所要−総発行、純発行＝総発行−償還。期首の事業増分債務は固定両事業モジュールのゼロ初期値。総発行は教育・医療の既存モデル発行合計で、償還を自動借換えしない。全国借換え・国債発行・債務残高・完全PB・国債調達金利はN/A。政策金利0.75%は2026年アンカーのみに表示。
