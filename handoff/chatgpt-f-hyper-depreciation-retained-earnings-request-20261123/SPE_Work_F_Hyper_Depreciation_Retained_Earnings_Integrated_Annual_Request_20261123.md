## 3. 実装作業
1. **既存実装確認:** 現行統合Fと旧F動学・DM04/05・企業勘定の該当コード/入力/出力を自己回収。投資促進フロー、資本減耗 `depreciation`、法人税・税控除、利益剰余金、配当、資金調達の接続と欠落を短く対応付ける。既存PASSと原本は再生成しない。
2. **ハイパー償却:** 税務上の前倒し償却と経済的資本減耗を分離。通常償却との差分を年次法人税負担・税収・企業キャッシュ・投資誘発・資本ストック・GDPへ接続。償却の前倒しと後年反転、税務上の償却総額の整合、投資誘発がない場合の単なる時点移動を明示。法人税率の既存F経路を尊重し、税制優遇を他の投資促進・人材開発控除と二重計上しない。企業別実データがない場合は集計モデルと明記。
3. **内部留保:** 利益剰余金ストック、当期純利益、配当、自社株買い、資本・R&D・人材・賃金支出、現預金/資金調達を分離。**内部留保650兆円＝投資可能現金650兆円とはしない。** 利益剰余金増減は利益処分・会計調整で閉じ、設備投資等を機械的に利益剰余金から直接控除しない。2028年ガイドラインの対象範囲と説明・開示による行動変化は、根拠がなければゼロ効果基準＋明示的感度で計算する。40%超/未満の開示枝を分離。
4. **相互作用:** 優遇税制の「検討」を自動採用せず、税制連動OFFを既定、ONは非採用感度。投資促進・法人税減収・内部留保・賃金・消費・税収・資本の重複計上を防止。既存統合Fの医療・VAT・教育・年金・外国人材等の結果を保持し、変更した企業政策部分の差分を説明する。
5. **年次実行:** 少なくとも固定基準F、ハイパー償却のみ、内部留保ガイドラインのみ、両方ONの4枝×30年を計算。必要な感度（税務償却倍率/適格投資率/企業投資反応/ガイドライン効果/開示方向）を**限定数**追加。SQ・N3は既存固定比較値を用い、再計算・改変しない。差分は2055年に加え2028、2030、2035、2045などの中間年も示す。
6. **検証:** 年次会計恒等式、償却総額と時点差、課税所得・欠損時の扱い、資本蓄積、税収差、配当・利益剰余金整合、効果ゼロ枝の基準一致、二重計上防止、2028年以前のガイドライン効果ゼロ、非採用枝と既定枝の分離をテスト。未同定の政策効果を実測推計と称さない。
