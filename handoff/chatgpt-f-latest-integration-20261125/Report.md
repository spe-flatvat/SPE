# SPE｜F最新実装の包含確認・未接続補完・年次再計算

2026〜2055年。F0の30年を再利用し、F1〜F3の90ケース年次を実行した。F0/F1/F2は現行AのSQ・N3、F3はP3のSQ・N3と同じ条件で比較する。F0〜F3は今回の系列名。

## 包含と接続

共通FはLATEST_Fを基に医療参照を共通接続した系列。外国人材、高齢就労、教育・訓練、医療・終末期、A・B・C基礎フロー、VATの段階税率・税収・賃金帰着、家計需要の代理、教育・医療の部分財政は既に計算されている。施策本文・Annexとの対応は [Inclusion.csv](Inclusion.csv)。中間層第4段階の観測比率配賦・条件付き負担・A逓減・C同年再配分・B固定利用は、現行共通Fに含まれていなかった。

F1では同じ年次の現金代理・B現物資源・VAT購買力・部分財源を接続し、合成家計の固定参照を併記した。現行共通Fに重複せず追加できる採用済みGDPフローは確認できず、F0とF1のGDPは全30年一致した。

F2は第4段階の非採用感度を接続した。固定ランタイムで元の合成世帯セルを再生し、第4段階の配分表と照合した。世帯構成・適格性は公表済み感度のものを維持したうえで、賃金とCは配分比率を現行共通Fの既存プールに適用した。2055年のCは家計感度元の5.007487兆円に対し現行共通Fで5.041229兆円、VAT賃金はそれぞれ1.297091兆円と1.303349兆円。元系列の金額を共通Fへ丸ごと移さず、A・C・Bの変化と、所得税・住民税・本人年金の受取差を記帳した。

VAT賃金総額は既存ケースに入っているため、汎用MPC×賃金総額から、既存のセル別MPC×追加負担控除後の賃金への差分だけを需要へ入れた。Aの控除戻し、Cの配分差、Bの私的支出代替・公的サービス差は別項目。VATバスケット効果は既存代理を保持し、新たな現金・税収・GDP加算は行わない。名目需要差に既存の国内比率0.8を適用し、残る0.2を輸入相当の代理とした。実質化して需要状態へ既存係数0.6で平滑化し、供給上限と価格圧力を適用した。税弾性・企業投資・労働・既存医療などへの二次反応は固定した。

F3は前回の回復Cの需要・供給容量に同じ増分フローを接続し、その増分をP2の価格係数で実質化した。医療・税額・給付・合成家計の入力はF2参照のまま。現行FからF3への名目差を、現行価格で評価した回復C、P2価格への変更、今回接続差に分解した。v6標準ランナーの消費税一時物価項は0で、VAT固定バスケットをGDPデフレーターへ転用しない。
