### A. 合成世帯実質中央値の横ばい要因分解
1. Stage 1の `Distribution.csv`, `Annual.csv`, `Common.py`, `Run.py`, `Replay.py`, `Dependencies.json`, `Report.md` と固定依存を取得。29所得セル、所得頻度、年齢プロファイル、世帯数・重み、所得五分位の税・保険料、A軽減・基金・C現金、B現物、増分所得税・住民税、共通デフレーターの定義を保持。
2. 2026〜2055年の名目中央値、実質中央値、給付前/後中央値、給付前/後ジニ、中央値付近のセル・順位・世帯重み・所得推移を再計算。名目所得伸びと物価デフレーター、税・保険料・給付、所得セル構成・順位移動の寄与を、**再計算可能な反実仮想または厳密な恒等式**で分解する。中央値は非線形なので加法寄与が厳密に一致しない場合、交互作用・残差と分解順序を明示し、単純な平均寄与を中央値効果と呼ばない。
3. 特に「中央値順位の世帯には給付前後の差がない」という既存Stage 1の説明を、実際のセルと年次で検証。ジニ低下と中央値横ばいが両立する理由を分布上で説明。政策効果と既存合成入力・物価仮定による機械的結果を区別。全国ジニ・全国所得/賃金中央値はN/Aを維持し、2035年ジニ自動発動を起こさない。
4. 固定F基準の再現、年次分解の残差、デフレーター基準年、重み合計、給付の二重計上防止、独立プロセス再実行とCSV一致を検証。

### B. 教育・医療増分財政の未割当資金所要の原因分解
1. Stage 2の `Annual.csv`, `Comparison.csv`, `Run.py`, `Dependencies.json`, `Report.md` と教育・医療固定モジュールを取得。既存の定義 `PB=純歳入−純歳出`, `資金所要=利払い−PB＋償還＋金融資産取得`, `未割当=資金所要−総発行`, `純発行=総発行−償還` を変更しない。
2. 2026〜2055年の未割当を、教育・医療の歳入/歳出、利払い、償還、資産取得、既存発行に追跡可能な内訳で年次分解。2055年の未割当2.657兆円とPB−2.600兆円、利払い0.678、償還2.011、総発行2.663、純発行0.652、期末債務33.229を再現・整合確認。既存教育債・医療債の発行設計、償還スケジュール、会計範囲、財源不足を識別し、**モデルで発行・借換えを未指定なのか、財政構造上の不足なのか、勘定漏れ/重複なのか**を区別する。
3. 必要なら不足額をすべて借入で埋める等の**非採用・条件付き資金調達感度**を別枝で試算してよいが、固定Fの発行・債務に追加計上しない。国全体のPB、国債発行、借換え、国債残高、金利・債務持続性は、データ不足ならN/Aを維持。未割当を自動的に国債発行と同一視しない。
4. 年次の資金恒等式、発行と償還、債務ストック、利払い、既存部分財政への再加算禁止、別プロセス再実行とCSV一致を検証。
