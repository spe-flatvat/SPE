# F中間層 第1段階 給付・負担整合化

2026〜2055年の非採用感度。固定Fの年次C支出を予算上限とし、賃金帰着後の名目世帯所得500万円以下に固定Fと同じ基準消費額ウェイトで再配分した。適格セルの消費額ウェイトがゼロなら当年予算を未配分とする。固定経路は追加予算方式で、VAT増収枠によるC充当と基金引出しはいずれもゼロ。Cの再配分は追加財源の発生を意味しない。

Aは固定世帯モデルの関数を使用。保険料負担を基礎とし、200万円以下は最大35%（導入期は段階適用）、200〜500万円で線形逓減、500万円で軽減率ゼロ。軽減に伴う保険者減収は固定Fと同じ全額公費補填・準備金ゼロの帰属で記録。A軽減後の所得税・住民税の控除戻しは元モデルの課税代理で再計算した。

賃金増分を配賦し、負担控除前の名目世帯所得でA/B/C判定。賃金増分から本人年金9.15%を控除し、残る額の70%に所得税・住民税各10%を別々に適用。A軽減による控除戻しと非課税Cを計算し、現金可処分所得に反映する。限界負担とA控除戻しは別計算。課税単位、個別控除や加入等級、両課税経路の税率帯の交互作用は未較正。受取側との照合は家計診断の勘定内で行った。

2043年の観測比率配賦では合成約93.43万世帯が500万円境界を上抜けた。Cは0.263650兆円を再配分し、支給3.978633兆円・未配分ゼロ。Aは0.533158→0.530760兆円。2055年はC支給5.007487兆円・未配分ゼロ、Aは0.349244→0.348150兆円。2055年の賃金増分に係る本人年金・所得税・住民税の受取は合計0.283661兆円。Gross枝は配賦基準だけを総所得へ切り替えた感度。

`Annual.csv` は2枝×30年、`Cells.csv` は観測比率統合枝の全セルで、A/C配分前後・負担・受取・境界を記録する。集計金額は当年名目。

## 再実行

依存原本は `Dependencies.json` の固定参照から取得する。runtime_sources は fixed_path で取得し、runtime/ 以下の path に保存する。ルートから次の2コマンドを実行する。

```sh
python handoff/chatgpt-f-distribution-fiscal-integration-20261123/stage1-distribution/Replay.py runtime handoff/chatgpt-f-hyper-depreciation-retained-earnings-20261123 replay
python handoff/chatgpt-f-middle-class-integrated-20261123/stage4-integrated/Run.py runtime replay output
```

別プロセスで固定Fのセル復元から再実行し、4段階で生成した年次・分布・検証ファイル11点の全バイトが一致した。
