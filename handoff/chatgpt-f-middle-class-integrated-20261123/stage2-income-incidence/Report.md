# F中間層 第2段階 所得帰着

固定F、先行総所得、観測比率、観測比率＋負担、観測比率＋打切り、今回の観測比率統合・総所得統合の7ケースを2026〜2055年で計算した。先行5枝の年次原本150行は固定原本とバイト一致を確認した。中央値と順位は世帯重み、ジニは世帯規模の平方根で除した現金所得に世帯人員重みを適用。Q1〜Q5は固定F参照所得の五分位で、ケース間で同じ所属を比較する。

2055年の統合枝の実質現金中央値は424.998万円（固定F比+1.164万円）、第2・第3・第4五分位の平均差は各+0.322、+0.753、+1.490万円。中央値セルにA/C支給はなく、同年の中央値は負担のみ枝と一致。2043年第2五分位は固定F比−0.454万円、打切りのみでは−1.372万円。総所得基準の統合枝では同年第2五分位が+0.308万円であり、配賦方式で符号が変わる。

構成感度では所得ノードごとに世帯数を保ち、存在する世帯プロファイルを等ウェイトにして固定Fと統合枝を再集計した。資金台帳は固定ウェイトの計算を使用し、等ウェイトは同じセル結果の構成感度。2043年のジニ差は固定重み−0.000203、等ウェイト−0.000505。2055年は+0.000323と+0.000050。観測所得比率は二人以上の勤労者世帯の代理で、全国を代表する配賦や因果推定の根拠はない。

`Groups.csv` は全体、五分位、世帯プロファイルおよびQ2〜Q4とプロファイルの交差表。実質列は2026年価格。当年名目の `net_benefit` は賃金本体を除いたA＋Cから控除戻し・追加税・追加本人年金を引いた額。
