# F中間層 第3段階 現物給付と購買力

Bは名目世帯所得300万円以下。固定Fの利用率75%、供給容量80%、重複除外25%と固定サービス価格を使用。賃金帰着で境界を出たセルの支給のみ失効する。今回の賃金増分は非負で、新規流入はない。受益は利用価値、費用はサービス原価と事務費として別列に記録。Bの利用価値は現金には入れず、現物込み資源では1回加えた。

VAT直接価格便益は固定Fの消費額ウェイトを使った固定バスケット値。固定Fの合成現金セルにはVAT価格効果が入らず、参照する共通デフレーターはVATフローの前にコア成長・インフレで決まるため、現金と価格便益を足してから同デフレーターで割る補助指標を算出できる。これはBを除いた固定バスケット購買力の近似値で、実際の品目別物価指数や価格・需要の反作用を伴う統合購買力はN/A。価格便益は各ケース共通であり、固定Fとの差には加わらない。

2055年の合成家計全体の名目VAT価格便益は10.014975兆円、B利用価値は0.240816兆円。Q2/Q3/Q4のVAT価格便益は1世帯当たり2026年価格で7.585 / 10.435 / 13.571万円。2055年のQ2〜Q4と中央値セルではB利用価値ゼロ。中央値セルの実質VAT価格便益は11.234万円で、現金中央値424.998万円とは別に表示する。各年の固定Fとの差、固定バスケット値、現物込み資源は各CSVを参照。
