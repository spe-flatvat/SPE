## 第1段階｜給付・負担計算の整合化
1. **C現金給付**: 既存C給付年次予算（既存VAT資源プールと他用途の配分・上限制約を保持）を固定し、当年の名目世帯所得で適格性を再判定し、適格セルに同じ年の未使用額を再配分する非採用枝を実装。まず先行の配分ウェイト/優先順位を原本から確認し、根拠があればその規則を再利用。再配分規則が原本にない場合は、適格世帯重み比例など明示的な**非採用代替規則**を実装し、正式Fの規則とは呼ばない。適格対象がゼロなら未配分残を残し、予算保存を捏造しない。基準の支出予算、実際の支給、未配分額、配分前後のセル受給額を年次で閉じる。C予算を自動増額しない。
2. **A社会保険料軽減**: 名目世帯所得200〜500万円の既存逓減関数、500万円境界、低所得の軽減率、保険者負担帰属を原本から復元し、賃金帰着後の適格性・軽減額を再計算。関数が未定義なら根拠なき補完を固定Fに入れず、明示的非採用関数の比較と未計量を区別する。AとCの同一VAT資源/基金の二重充当禁止。
3. **限界税・社会保険料**: 先行の所得税・住民税・本人年金の仮定を基準として、所得増分・控除・給付判定の適用順序を明示。実際の課税所得/加入情報がない場合は条件付き感度のまま。家計控除と受取勘定を同額で照合し、固定F全国税収や財政に再加算しない。
4. 境界の出入り、負担と給付の同時適用による非線形効果、世帯セル別の資金保存・受給額非負・上限を検証。

3. 観測所得比率は二人以上の勤労者世帯の条件付き代理であり、雇用主・受取世帯の因果的対応や全国代表性を示さない。固定合成世帯重みと賃金配賦方法の感度を実計算し、世帯構成の仮定に依存する部分を区別。外部統計の再収集を目的化しない。
