# F施策の接続確認と免税点240万円の年次感度

Annex §1Cの免税点を、旧Fの制度表示から年次税収・企業資金・投資・資本・部分財政へ接続した。固定Fを再現するOFF、施策ONで効果ゼロ、施策ONの非採用感度を2026〜2055年の3枝・90行で実行した。

2028年は既存Fの行政改革開始年を借用した感度上の開始年。売上239・240万円を免税、241・500万円を課税側とする例示バンドを置いた。従来の課税・登録経路や三分野の損税モデルに入っていない既免税残余取引を仮定し、240万円超の控除調整後の税込換算ベースを2026年規模で1兆円に設定した。対象母集団、実際の課税純増、仕入・買手控除および転嫁は未較正。標準税率を適用し、税込価格を固定して売手が納税分を全額負担する。既存の企業資金→投資係数0.3を一度適用する。VAT増を税収と企業資金に反対符号で一度ずつ記帳し、VATの内訳はマクロ税収に重ねて足さない。既存のC給付とVAT予測超過基金は固定。事業者側の納税追加から家計への直接転嫁はゼロとし、既存のGDPフィードバックによる間接影響は残る。

## 再現と残件

新規7,771件PASS、失敗0。240万円境界、発動前とONゼロ、固定Fの重複10指標、資本恒等式、税込税額と売手負担、税収・部分財政・各給付の帰属を検証。別プロセス再実行による基礎年次・トレースと2つの年次CSVは実バイト一致。既存PASSは加算していない。

Dependencies.json のとおり Runtime_Sources.json と既存Legacy_Annual.csvを取得する。Runtime_Sources.json の各固定原本を指定の path で runtime に配置する。各ケースを独立プロセスで `python Run.py runtime prior runs/<ケース> <ケース>` と `python Run.py runtime prior replay/<ケース> <ケース>` で実行し、出力先を作成して `python Compare.py retrieved/Legacy_Annual.csv runs replay exports` を実行する。

Coverage.md に既存接続と残件を記載した。主な残件は省庁のデジタル捕捉による独立増収、企業別ガバナンスと行動、全国ジニに基づく2035年条件、医療の実測成果、施行順序変更と追加債務の閉じた財政勘定。旧F基準、固定SQ/N3、政策本文・Annexを維持。感度仮定の正式採用はOwner判断に留保する。
