## 3. 作業B：実行可能な限定感度計算

まず実装コードと入力契約を確認し、既存隔離ランタイムの**実際に作動する**仮定のうちGDP・税・家計・財政への影響が大きい候補を優先する。最低限 `firm_rate=0.75`、雇用人数・給与差額・移行期間、現物給付の家計代替率・保険者負担等を候補とするが、変更不能・他の未承認選択と不可分ならその制約を記録する。値を変えるだけで計算経路が変わらない不活性パラメータは、実行前に切り分ける。

各感度枝について**原文が許容範囲を明示している場合はその範囲**、明示していない場合は現行値を中心とする**未採用の機械的感度テスト値**（例：現行値の上下変動）として明記し、政策案・推奨値・正式採用値と呼ばない。テスト値と変更幅はコードの許容域・経済的意味を確認し、恣意的な新しい固定政策仕様にしない。Ownerの選択を要求せずに実行できる範囲だけ進める。

- 基準は `N3_NATIVE_COMPLETED_SUPPORTED`（追加G/I OFF、原文に基づく新規金銭効果なし）。既存GDP−SQ 2030年−7.595361131兆円、2055年−44.970844763兆円、SQ割れ26年を再利用。条件付き雇用3年枝は別扱い（2030年旧N3比＋0.005477776兆円）。
- 追加G/I診断の基準経路は未採用として固定し、**今回の感度枝へ混入させない**。企業75%再投資のようにN3既存経路にも残る診断仮定は、変更による効果と「原文の効果」を区別。
- 実行可能な感度枝を2026–2055年で計算し、2030・2035・2039・2055、GDP−SQ、実質・名目GDP、税、家計所得・消費、民間投資、PB、利払、現金・債務、関連部門勘定を比較。SQ共通外生条件を保持。
- 変数間の依存・重複・会計閉合を確認。単一変数の変更が不可能なら、連動変更を明記し、独立な感度効果と呼ばない。原文・制度仕様不足や統計不足を仮定値だけで「解決済み」にしない。
- 感度値が妥当な現実予測でない場合は **mechanical sensitivity / unadopted** と明示。統計データが取得可能なら出典・対象年度・定義・適用可能性を確認するが、外部データ収集を無制限に拡張せず、未取得をunknownとする。
