## 実成果と原因

79ケース×30年=2,370行を国内移転候補で再計算し、既存挙動・海外所得・追加VA候補も各79ケース実行（計9,480ケース年）。国内移転候補をさらに再実行し23 CSV実バイト一致。Fは ff6210061615105de9a0d64767c256796be80ed2 の LATEST_F 固定参照のみ、今回再実行していない。

Claude L3を原本とコードから確認した。旧 `Build_Results.py` が -fund_return を表示するだけで、`N3_Components.py` の `cash += pension_delta + fundpay` に相手方控除はない。旧R0/R2/R4の2055 GDPは518.507629544 / 518.575857423 / 518.664651920。R4−R0=0.157022376兆円を再現した。ただし、これは旧運用利回り感度であり、相手勘定是正額ではない。基金運用益は当年全額消費されず、一部は基金に残るためでもある。

経路: 既存拠出を基金へ振替（公的制度は同額の拠出を失う）→期首資産×利回り→基金留保/75歳以降給付→家計現金→共通MPC・国内消費比率・デフレータ→Ctarget→GDP/所得feedback/税/政府部分収支。現コードの基金拠出・資産単価は固定SQ人口/物価依存で、内生GDPで再計算しない。したがって今回の相手勘定是正では基金残高は変わらない。追加実物投資や国債発行を基金運用と同一視しない。

国内移転候補では、既存家計金融所得を減らし基金の所有者へ留保するため、国内の新規一次所得は0。基金所得と家計所得の部門間振替であり、新規付加価値を発生させない。一方、当年消費から基金貯蓄への移動や給付時期の違いを通じ、実際のGDPは需要に反応し得る。「移転だからGDP数値差を必ず0にする」という実装は行わない。基金運用益を直接GDPから引いていない。金融部門全体の利益・バランスシートは未実装であり、相手方を金融機関の自己資本だけに断定せず最終家計所得プールへの帰属候補としている。

運用益は既存利回り定義のまま純受取または非課税と仮置きし、追加の20%税や税控除を創作しない。税の変化は既存のマクロ税反応であり、利子所得税の完全な再構成ではない。金融20%課税の個票ベースへの配賦・国内/海外比率・既存所得源泉との実測対応はOPEN。海外所得や追加VAを根拠なく正式採用しない。資産値上がり益を当期生産/所得として追加していない（利回りの内訳データがなく評価益割合はOPEN）。半官営医療基金は今回の対象外で、旧経路を保持する。

## 比較可能性と次の障害

`Comparability.md` と `Key_Years_Comparison.csv` は2026/2035/2045/2055を収録。共通単位・エンジンでSQ差を計算できるが、FとN3の接続範囲が異なり政策因果順位は出せない。既存N3の `macro_cash_DI_proxy_trn` はraw resource DIを上書きしており、Fでは価格便益控除後のcash proxy。同名のまま直接比較しない。主要年表ではN3から価格便益を引いた定義整合proxyを別名で算出した。元の旧列を無関係に変更していない。

残存障害は3点: (1)全国税・社会保険・地方・国債初期ストックと資金循環の完全接続不足。AIは定義の対応付けと取得可能統計の接続を進められるが、国地方配分や財源方針はOwnerの政策選択。(2)所得源泉・MPC/弾力性・基金収益源泉の未較正。AIは実データで比率と感度を更新可能、国内/海外の採用比率や負担配分はOwner選択。(3)F/N3の政策接続範囲と外国追加者の社会費用・健康QOL等の不足。AIは共通出力対応と費用接続を実装可能、外国GDP5%定義等はOwner選択。今回はいずれの裁定も要求せず候補結果を引き渡す。
