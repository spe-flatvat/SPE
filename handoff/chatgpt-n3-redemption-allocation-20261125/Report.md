# SPE｜N3債務償還配分調整・成長財政感度計算

**確認済み権限を適用した下限では、新たなG/I配分は0。仮想利用では一時的なSQ逆転が起きたが、2055年まで持続した経路はなかった。** Cの2055年実質GDPが最大の100%・Iのみでも、SQまで25.888兆円の差が残る。

## 原本・資金境界

N3本文の財政自律目標、移行期、支出優先順位を照合した。N3専用Annexは既存原文監査で未特定。本文・共通Annexから、最低償還・法定繰入・満期別元本を除いた裁量償還額、その分母、開始年度、債務ゼロ後の用途を一意に特定できない。前段の国・地方資金勘定、財源利用権限、G/I執行主体の固定資料でも、事業別の歳出権限・現金所在・負担主体を確定できない。このため確認額は下限0とし、中央政府・自治体の実際の利用可能額はN/Aとした。

仮想枠は固定C/Dの**現金余剰による純償還候補**と、その年の当該枝の支出前現金余剰による償還候補（期首債務以内）の小さい方。指定25/50/75/100%はこの枠への削減率。借換・満期の支払停止、SFA、基金、既存金融資産の取崩し、新しい起債・政府間振替は枠に算入していない。既存ロールオーバー比率0.1を維持し、既存式で生じる借換額を発行と償還の両側に同額計上。2055年の固定PB候補や資産残高も追加G/I枠には使わない。

年次順序は前年状態・利息 → 支出ゼロでの税・連結残余 → 当年の仮想償還削減枠 → G/I → GDP・税を再計算 → 償還・資産・資本を翌年に繰越。誘発税収は当年の配分枠へ先取りせず、実行後の償還額に反映する。Iは既存の平滑化、国内比率、資本減耗・供給式を適用し、当年枠の未執行分は部分現金資産に残す。G/Iは既存G/I OFFの上への新規適格支出の仮定で、既存給与・現物給付・移転を重複加算していない。借換条件や新規資金源を追加していない。既存財政候補に内在する借入フローは別列で表示した。
