## 2. 共通財政ランタイム実装
主体×年×取引分類×相手勘定を基本に、税（所得・法人・消費・その他）、社会保険料、その他収入、社会給付、医療・教育、政府最終消費、資本形成、その他基礎的歳出、利息支払/受取、移転、金融取引を区分。医療・教育・給付と政府消費等の分類重複を排除。税代理226.687兆円（2055 C）は既存診断値であり全国税収と同定せず、税目・基盤・対象範囲の橋渡しを作る。既存SQ税・医療・人口等の年次式を優先。未定義の伸び率・弾性・金利は根拠ある限定推計のみ別識別、根拠なしはN/A。既存マクロG/Iを財政支出として再加算しない。
主体間移転・内部利息・内部債権債務を相手勘定と照合し連結消去。不一致は残余として報告し相殺で隠さない。PB（利息の扱い明記）、財政収支、資金収支、総債務、金融資産、純債務（対象資産定義明記）、発行・元本償還・借換、SFAを区分。期首債務＋発行−償還＋債務SFA＝期末債務、資産も独立ストックフロー式、前年末→当年初を実装。元本償還を基礎的歳出に含めない。資金不足は明示し、原本にない自動起債・増税・歳出削減・資産取崩し・勘定間充当を導入しない。既存資金調達規則が不足する場合、PB等の計算可能部分は継続し、債務経路は条件付きまたはN/A。恒等式の残余を架空取引で埋めない。
F/N3用の再利用可能な入力・差分/置換インターフェース（主体、取引、相手、単位、年度、根拠、既存基準との重複、状態、未割当）をコード化し、小規模な合成入力で二重計上防止・連結消去・欠損伝播を検証。実際のF/N3財政接続・政策変更は次回。
