## 3. 必須の実行・分析

1. **取得と定義確認**：SQの2026〜2055年の年次データ、人口、就業・有効労働、実質・名目GDP、GDPデフレータ、消費、投資、資本、供給能力、生産性、税収等の存在列と計算式を確認。欠落項目は明示し、推測で補わない。
2. **年次成長の再構成**：各年の実質GDP水準、前年比、累積変化、2026基準指数を計算し、既存出力との誤差を記録。2026→2035、2035→2045、2045→2055、全期間を表示。
3. **数値分解**：共通マクロの実際の計算式に沿って、人口・就業／有効労働、労働生産性・外生基調成長、資本ストック・減耗・投資、消費・需要調整、移民・人口動態、供給制約、災害・税等の作用を可能な限り年次の加法寄与（兆円）または成長率寄与（%pt）として分解する。恒等式として加法分解できない要因は、順序依存を明示した固定基準アブレーション／反実仮想とし、加法寄与と混同しない。交互作用・残差を別列で表示し、合計が実際のGDP変化と整合するか検査する。
4. **「SQ成長バフ」仮説の判定**：基調成長1%等の外生項がどこに入り、人口・労働・移民・資本・需要とどう合成されているかをコードと数値で確認。二重計上、過大な正寄与、成長率の取り違えの有無を検査する。疑惑が成立しない場合も `NOT_SUPPORTED` と理由を示す。仕様上の成長押上げと不具合を区別する。
5. **他シナリオとの切分け**：SQの共通経路とF固定参照・N3候補の差を、比較可能な列と年に限って表示。N3の2035年政策税差分約+85.8兆円、2055年家計現金差分約−153.8兆円、MPC感度の逆符号、旧N3投資残余の負値はN3固有の別論点として明示し、SQ縮小の原因に転用しない。Fは固定参照で再実行していないことを保持。
6. **検証**：計算式・出力列・再構成値・残差・アブレーション前提を独立に照合。確認できた原因、疑わしい原因、未識別要因を区別し、数値根拠と出典ファイル・列・式・年を示す。モデル修正案は必要最小限の候補にとどめ、実装しない。
