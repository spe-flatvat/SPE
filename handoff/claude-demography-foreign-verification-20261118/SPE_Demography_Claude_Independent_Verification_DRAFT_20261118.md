## 5. GDP比5%(重点3)

### 5.1 参照式の意味

`GDP比 = 外国人ストック × 0.000008兆円 ÷ コア名目GDP`(1人800万円)。分子は**在留者全体**の人数です。報告書が述べるとおり「全在留者1人800万円、就業率等不使用」です。

### 5.2 初年超過の原因(私の計算)

| 分子の取り方 | 2026年のGDP比 |
|---|---:|
| モデル 200万人 | 2.67% |
| 在留者 2025年末 4,125,395 人(報告書の「約5.50%」) | **5.50%** |
| 在留者 2026年6月末 | 5.71% |
| 届出外国人労働者 2,571,037 人(同じ式) | **3.43%** |

- 800万円/人は、名目GDP 600兆円を就業者 7,500万人で割った値に相当します。実際の就業者は 6,828万人で、1人あたりでは約 879万円です。つまり800万円は**就業者1人あたり**の水準と整合する値です。
- ところが分子には、非就労の家族・児童・学生・永住者・高齢者を含む在留者全体(4.13百万人)を入れています。届出労働者は在留者の約62.3%(2,571,037/4,125,395)で、就業者に占める割合は約3.8%です。
- したがって**初年超過の原因は、現行式が「在留者 = 就業者」として扱っていることです。** 実績を使うと直ちに5%を超えるのは、経済寄与が5%を超えているからではありません。
- 就業者のみ(在留者の62.3%と仮定)で数えると、5%超は END25・共通流入 327,557 の場合 SQ 2040、F 2038 年です(式どおりでは 2026 年)。人口比5%超(2034年)より**後**になり、順序が入れ替わります。この62.3%は2025年の実績比率の固定仮定で、将来の増分が同じ比率で就業するとは限りません。

### 5.3 解釈上の問題

- **「GDP比5%以内」の原文の意味は未確定**(Annex 5 は「総量管理:GDP比5%以内上限」。分子が人数なのか寄与額なのか、分母が何かは文言から決まりません)。報告書も「現行式から受入停止の政策結論は出せない」と述べており、同意します。
- 現行式の「超過年」は、定義(分子)の選び方でほぼ全期間にわたって動きます。この式の超過を、政策可否や受入規模の判断材料にしないよう、Owner 側でも注意が必要です。
- 参考として、式を変えない場合の2055年は、END25・SQ で 10.51%、F で 11.81%。就業者のみなら 6.55% / 7.36% です。いずれも5%を超えます。

### 6.2 計算上の妥当性

- 台帳(ストックを年400,000ずつ増やす)の算術は正しく、モデルの ANNUAL400_2027 経路とも一致します。5%超の初回年は END25・JUN26 で 2031、LEGACY で 2036、2055年は 15,725,395人・17.873% です。
- **F(TOTAL_TARGET)は共通流入の水準に依らず同一の経路になります**(4水準で実質GDP・ストックが全年一致。再導出して確認)。F の総流入が一律 400,000 だからです。そのため「F−SQ のGDP差」は、SQ 側の共通流入の仮定で 14.55〜27.71兆円と大きく動きます(下表)。

| 共通流入(SQ側) | F の追加人数(2055年累計) | F−SQ 実質GDP(2055年) |
|---|---:|---:|
| 357,000(旧SQ逆算) | 1,118,000 | 20.378兆円 |
| 303,315(直近3年平均) | 2,513,801 | 27.706 |
| 327,557(2025年) | 1,883,518 | 24.390 |
| 400,000 | 0 | 14.550 |

- 共通流入=400,000(F の追加ゼロ)の 14.55兆円が、F の移民以外のチャネルの効果です。357,000 との差 5.83兆円が、追加 111.8万人の寄与で、1人あたり約 520万円に相当します。**移民の追加分の GDP 効果は、SQ をどこに置くかで決まる量です。**

### 6.3 目標(人口比3〜5%)との量的な整合(Owner 判断に直結)

- モデルの人口基準(出生 −2.5%/年、死亡 +1.5%/年)で、**流入がゼロでも**、在留者 2025年末(4,125,395)を初期値にすると 2055年の人口比は 5.40%(初回5%超は 2053年)になります。分母が縮むためです。
- 2027年から一定の純流入を置いたとき、2055年に5%ちょうどとなる流入は、**ゼロ以下**(純流出が必要)です。100,000人/年で 8.86%、327,557人/年で 15.86% になります。
- 注意点として、この結論はモデルの分母(2055年 76〜87百万人。社人研中位は 100.5百万人)に依存します。分母が大きければ余地は増えますが、社人研中位の分母(100.5百万人)で概算しても、5%以内で許容できるストックの純増は約 0.9百万人(2055年まで年3万人程度)で、年30万〜40万人とは桁が違います。
- すなわち**「人口比3〜5%維持」と「年間 30〜40 万人」は、同時には成立しません。** どちらかを優先する判断が必要です(§8)。

| 40万人の位置付け | 「国際純移動 400,000」か「ストック純増 400,000」かで必要な勘定が変わる(差 約1.4%)。F が TOTAL_TARGET の間は、F の移民追加分は SQ の水準で決まる点に注意 |
| 人口比3〜5% | 年30〜40万人規模の流入とは量的に両立しない(§6.3)。**目標を守るなら流入規模を、流入規模を守るなら目標値を**見直す必要がある。どちらを優先するかが最も大きな判断 |
| GDP比5% | 現行式は初年から超過する構造(§5)。分子(人数/就業者/寄与額)・分母・「以内」の意味を先に定義する。現行式の超過年を可否判断に使わない |
| 保持率・就業接続 | 未較正のまま使われている。就業接続 0.6〜0.8 で F の 2055年実質GDPが −13.9〜0兆円動く。ここは Owner 判断ではなく、データ側の整備(年齢・在留資格別就業)が先 |
| 供給制約 | slack 2% では F が26年拘束し DM-04 の差が隠れる。5% 以上では拘束せず上限なしと同じ。2% は未較正なので、結論は両方併記 |
| 人口動態の共通基準 | モデルの分母は社人研より 13.7百万人小さい。比率の絶対水準はこの差を含むため、人口動態エンジンの置き換え(社人研コーホート)は優先度が高い |
| 社会統合・適正規模 | 人数だけでは決められない(報告書に同意)。指標の定義を先に決める |
