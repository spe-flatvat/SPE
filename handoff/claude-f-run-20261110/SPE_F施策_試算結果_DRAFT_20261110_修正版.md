**DRAFT・非正式。** F施策を、2026年を計算に含める形(30期間)で、v6エンジン関数を使って走らせた結果です。2055年の実質GDPは661.5兆円(年率+0.44%)、人口は8,450万人、税収は名目GDPの22.4%(最大)で、国債発行は2045年までに0になります。HOLD・承認条件には触れていません。

## 結果(単位:兆円。人口は万人、賃金は万円)

| 項目 | 2026 | 2035 | 2045 | 2055 |
|---|---|---|---|---|
| 実質GDP | 568.6 | 568.2 | 613.9 | 661.5 |
| 名目GDP | 612.2 | 768.6 | 1,010.8 | 1,325.8 |
| 税収 | 82.4 | 105.8 | 174.2 | 297.4 |
| 税収の名目GDP比(%) | 13.5 | 13.8 | 17.2 | 22.4 |
| 歳出 | 110.7 | 136.9 | 158.1 | 174.6 |
| 国債発行(歳出−税収) | 28.3 | 31.1 | 0 | 0 |
| 人口(万人) | 12,051 | 11,151 | 10,005 | 8,450 |
| 賃金(中央値、万円)※ | 400 | 507 | 660 | 860 |

- **谷:** 実質GDPの最小は2027年で、前年比−4.5%(石油ショック−3%に続く、リスクショック−5%の年)。2035年に568.2兆円まで戻り、その後は伸びます。
- **国債:** 2040年に12.4兆円まで減り、2045年には0です。税収の上限(名目GDPの30%)に達する年はありません。
- **※賃金は出力ではありません。** 2026年400万円と2055年860万円の2点を結んだ入力値(アンカー)で、年次計算の結果ではありません。表の途中年は、その2点を幾何補間した私の仮定です。
- 2026〜2055年の実質GDP年率は+0.44%。2026年を含めない形(v6エンジンの既定)では682.4兆円・8,670万人で、約3%高くなります。

## 計算条件と出所

式と係数はシミュレーション条件仕様書 v5(Project 版、§3〜§8)に依拠し、計算は GitHub `spe-flatvat/spe` の v6 エンジン関数(commit `a40f070e`、`engine/prototype.py`、`engine/m14_wage_anchor.py`)で行いました。

| 要素 | 内容 | タグ |
|---|---|---|
| 実質GDP成長率 | 基調1.0% + 施策効果−リスクショック + (1−α)×(人口増加率 + エイジングドラッグ)。α = 0.35 | αは[推定] |
| Fの施策効果 | 消費刺激 0.3→0.5→0.7%(2027年まで／2031年まで／以降)、投資促進 0.3→0.5%(2029年まで／以降)、教育 0.3%(2028年から) | v5 §4 |
| リスクショック | 2026年 −3%(石油)、2027年 −5%、2031年 −3%、2029年起点で三年ごと −1%、2027年起点で隔年 −0.5%。インフレ上乗せ 2026年 +2pp、2027年 +5pp | v5 §3 |
| 人口 | 出生 = 前年×0.975×(1 + φ×実質賃金成長率)、死亡 = 前年×1.015、φ = 0.15。移民: 2030年より前は0、2030〜34年は線形に増加(2030年8万→2031年16万→2032年24万→2033年32万→2034年40万)、2034年以降は40万人 | φは[推定]、移民の増加の刻みは[仮定](定常値は v6 仕様 4.1.1) |
| 税収 | 前年×(1 + 名目成長率×弾性値)。弾性値 1.5(〜2032)／1.7(2033〜2040)／2.0(2041〜)、上限は名目GDPの30%、2031年は×0.90 | 弾性値の区切りは[近似] |
| 歳出・国債 | 歳出 = 前年×(1 + 2.5%〜2034／1.5%〜2044／1.0%〜)、国債発行 = max(歳出−税収, 0) | v5 |
| 賃金 | 2026年400万円→2055年860万円を幾何補間。出力ではなく入力値。出生率を通じて人口に影響 | 2055年値は v5、途中年は[仮定] |
| 初期値(2025年末) | 実質GDP 580兆円、名目 600兆円、税収 80兆円、歳出 108兆円、人口 1.215億人、出生 64万人、死亡 159万人 | v5 |

**2026年の扱い:** 2026年を計算の1期間目として扱い、CAGR は30期間で割ります(Owner 方針、2026-11-07)。

**照合:** v5 §8 の F 施策(661.9兆円、+0.44%、8,458万人、税収比 22.3%、国債 0)に対して、本結果は 661.5兆円、8,450万人、22.4%、0 で、差は GDP で約 0.06% です。エンジンを使わない別実装(式のみ)でも 661.5 で一致しました。

**再実行:** `python3 SPE_5case_recompute.py <engineディレクトリ>`(Project の `claude/SPE_5case_recompute.py`、SHA-256 `7504ebca…a202`)。年次値は `claude/SPE_F_yearly_extract.py`(SHA-256 `253a3737…3a37`)、または入力を別ファイルにした `claude/SPE_F_run_DRAFT.py`(SHA-256 `abe08349…b631d`)と `claude/SPE_F_inputs_DRAFT.json`(SHA-256 `e07756d3…56ac0`)で取り出せます。

## 仮定・未検証・食い違い

結果の読み方を左右するのは、賃金の途中年、移民の増加の刻み、弾性値の区切りの3点の仮定です。いずれも v5 に値がなく、私が近似しました。

**仮定(結果に効くもの)**

- 賃金の途中年(幾何補間)。出生率を通じて人口とGDPに効きます。
- 移民の増加の刻み(2030〜34年の線形)。定常値の40万人は v6 仕様にあります。
- 弾性値の区切り(2032年・2040年)。税収と国債に効きます。

- v6 仕様書と DecisionLog に、「2026年を計算に含める」の記載はありません。
