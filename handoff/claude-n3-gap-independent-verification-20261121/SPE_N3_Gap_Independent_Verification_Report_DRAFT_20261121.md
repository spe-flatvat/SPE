## 3. 領域別の結果

### A. VAT数量→実消費→GDP（A01–A18 全PASS）

- 2055年実質GDP（税の転嫁率0.8）: 弾力性0 = 526.234068、0.25 = 523.596278、0.75 = 518.464138。依頼書の値と一致。全転嫁率（0.6/0.8/1.0）で弾力性が大きいほどGDPが低い順序も成立。
- 旧価格モデル（VAT_ELASTIC_025／075）はどちらも 518.277707 で、弾力性に対して不感。
- 価格比を法定税率と転嫁率から独立に導出: `1 + 転嫁率×(新税率−旧税率)/(1+旧税率)`。HH標準・HH食品の986市場年行で観測値と最大差 8.0e-12。
- 数量 `q = clip(価格比^(−弾力性), 0.7, 1.3)` を再計算して最大差 4.9e-13。非家計市場は常に q=1。数量市場は HH標準・HH食品・非家計の3つのみで、医療・非課税は含まれない。
- 年次の数量変化額と置換される価格便益は、市場別合計と一致（最大差 1.6e-10、9.0e-11）。
- 需要目標の置換恒等式: 既存モデルでは `Ctarget = 家計国内消費比率×(MPC×(現金+フィードバック)+…)/デフレータ`。数量経路との対応ペア4組（新=Q_E0p25_P0p8等、旧=VAT_ELASTIC_025等）×29年=116行で、`ΔCtarget = ds/coreD×(数量増減額 − MPC×置換価格便益) + ds×MPC×0.08×Δ前年ギャップ`（ds=0.8、MPC=0.72、λ=0.6）が最大差 9.3e-11で成立。これにより、旧価格便益の二重計上、売上減少額のGDPへの再加算は経路上存在しないことを確認した。
- 税は1回のみ: `tax_diagnostic = マクロ税 + VAT差分 + 直接税差分` が全2,370行で成立（A16）。
- 2026年（初期年）に数量経路の流入なし（A17）。
- ゼロ弾力性の意味: 弾力性0では q=1、数量変化額0（A13）。旧モデルの価格便益（税率引上げによる実質所得圧縮項）が需要から除かれ、置換される数量項もゼロなので、旧モデル（518.278）より GDP が高く出る（A14）。したがって「弾力性0」は「旧モデルの弾力性0相当」ではなく別の定義である。旧モデルとの比較は、旧弾力性0相当のケースが無く、比較条件が異なる。
- `Q_ADD_LEGACY_*`（数量を旧価格項に加える残差モード）は価格便益を置換しない（A15）。旧項に数量効果を重ねる検討ケースとして意図どおりで、2055年GDPは SQ 比 −13.3／−18.5 と通常モデルより大きく低い。

### B. 部分財政・国債・保険（B01–B10 全PASS）

- 財政シナリオ7,110行（2,370行×利子0/2/4%）。追加政府未配賦から既存医療の純金融源を除いた残差の発行・償還・資産引出・資産積増・利払・期末ストックを、エンジン勘定（政府部分収支、SQ差、医療純金融源）から独立に再帰計算し、全列で差0.0。
- 全国PB／国債／国債発行は財政行・年次行ともに空欄（null）。初期ストック0は部分モデルの原点であり、全国国債0を意味しない（B03–B05）。
- 医療財源の直接税、政策税、VATの二重計上なし: `エンジン直接税差分 = 医療財源税 + 政策税差分`（B09）、`政策未閉鎖額 = 政府費用 − 保険者現金 − 政策税`（B10）。
- SQ_COMMON_ON は全利子で増分ゼロ（B08）。
- 利払ゼロのケースで利払ゼロ（B07）。
- ラベル `PARTIAL_CLOSURE_INCREMENTAL_UNALLOCATED_GOVERNMENT_ONLY`（B06）。

### C. フラット税・相続/贈与・所得源（C01–C14 全PASS）

- 2055年実質GDPのSQ差: FLAT_HH_SURVEY −34.609662、FLAT_SOURCE_LOW_LABOUR −23.554667（一致）。政策税差分: 110.345869 → 75.099265（一致）。
- 相続: 差額 = `(0.4×23.3846 − 3.2446)×物価指数×位相`、5ケース×30年で最大差 4.8e-11。基礎差 6.10924兆円。贈与: `(0.4×2.6761 − 0.3178)×指数×位相`、基礎差 0.75264兆円。相続と贈与は同一ケースで加算されない（C11）。
- EITCベースラインは全行で空欄のまま（C12）。
- 所得源感度の順序は実際の労働所得比率（SURVEY 0.95 > "HIGH" 0.80 > "LOW" 0.65）で政策税が単調（C05）。ラベルの注意（L4）参照。
- 労働・事業30%分と金融20%分の合計が政策税差分に一致（C06）。

### D. 外国人材・半官営保険・年金（D01–D20 全PASS）

- 外国人材パイロット（120行）: SQ既存ストックをキャップに先に充当し、追加受入と98%残存を独立再帰計算。キャップ・SQ指標・追加付加価値まで相対差 5e-12 以内。
- 2055年の追加滞在就労者: WAGE_BILL 0.05 = 68,953.6人（GDPのSQ差 +0.579240）、VALUE_ADDED 0.05 は0人（SQ既存ストックが既にキャップ超過）、0.001は両定義とも0人。依頼書の「68,953.6／0.0」は WAGE_BILL／VALUE_ADDED の順に対応する。共有SQ流入は不変（D08）。費用は未配賦（D09）。
- 半官営医療: 移管請求額は割合に比例、準備金・運用益・基金残高の再帰、保険料=給付、相手勘定=−運用益、公的純増0を一致確認（D11–D12）。準備金なしの同額移管は、同じ医療改革のみのケースと実質GDP・部分公的収支が同一（D13–D15）。2%準備金は家計現金を1対1で減らす（D16–D17）。
- 年金基金: 残高ロール（期首+拠出+運用益−支払=期末）と運用益=期首残高×0/2/4%、第二の家計控除なし（D18–D19）。
