## 1. モデルの式(部門 s、年 t、兆円)

R=非課税売上、P=p・R(課税仕入・設備投資、税抜)、τ0=10%(StatusQuo)、τF(t)=F の税率、κ=仕入税額控除の実現率、開始年 S 以降が「課税+控除あり」。

| 項目 | 式 |
|---|---|
| StatusQuo の損税 | L_SQ = τ0·P |
| F・開始前 | L_F = τF·P(税率低下のみ) |
| F・開始後 | L_F = (1−κ)·τF·P |
| 損税削減 | L_SQ − L_F(=税率効果 (τ0−τF)·P + 課税化効果 κ·τF·P) |
| 課税ベース拡大の税収効果 | ΔT_base = τF·R − κ·τF·P(開始後のみ。同一税率で未開始とした場合との差) |
| 税率効果の税収 | ΔT_rate = (τF−τ0)·P(開始前のみ。マクロの減税と重複しうるため別掲) |
| 帰着 | 公費補填 φ·τF·R / 消費者 (1−φ)·τF·R / 事業者残存 (1−θ)·κ·τF·P |

損税削減と税収増は**別の量**です(税収増は τ×付加価値に近く、損税削減の 2 倍規模)。同一視しません(基準書 §4)。

## 3. 構造から読み取れること(仮置きに依存しない部分を中心に)

1. **2038 年より前の「損税削減」は、課税化の効果ではなく単なる税率低下の効果です。** 5% への減税先行により、課税化が始まる前の 2028〜2035 年にも損税は約半分になります。この部分を「損税解消の成果」と呼ぶと、F の成否を誤って評価します。モジュールは `rate_part` と `base_part` を分けて出します。
2. **課税ベース拡大の税収増(ΔT_base)は、損税削減より大きいです。** ΔT_base は課税売上の税額から控除分を引いたもので、付加価値に税率を掛けた規模です。損税削減の約 2 倍です(基準ケースでは各年 1.95 倍前後)。「損税解消が税収を生む」という既存の物語と、「課税ベース拡大が税収を生む」は別の機構です。
3. **医療は公費補填の仮定で結果が反転します。** 診療報酬で出力税を全額補填(φ=1)する場合、医療部門の純財政効果(ΔT_base − 公費補填)は負になり得ます(基準ケース φ=0.9 で 累計 −5.6 兆円)。φ の置き方が全体の符号を決めます(φ_medical=0.5/0.9/1.0 で 全体の累計は 42.1/19.7/14.2)。F の診療報酬の設計は、Owner の裁定が要る最大の点です。
4. **κ(控除の実現率)を下げると、損税削減は減りますが、税収は増えます。** 控除を受けられない分が国庫に残るためです。κ は「執行の質」の指標で、国庫の観点では逆に作用します(F docx が κ<50% を監視指標にしている意味と整合)。
5. **開始年の前倒し・後ろ倒しは、損税削減の累計には効きにくく、税収側の累計に大きく効きます。** 損税削減の累計は 47.9(全部門2034)/45.0(基準)/44.5(全部門2038)ですが、ΔT_base の累計は 83.5/71.7/70.2 です。

## 4. 感度(21ケース、`sensitivity_summary.json`)

仮置きの p を ×0.75/×1.25 にすると、2040 年の損税削減は 1.36/2.27 兆円。〜2055 年の累計は 33.7/56.2(κ=1、開始年は基準)。κ=0.5 では 26.8〜44.7。不確実性の主因は p(部門データ)と φ(公費補填)です。開始年の違いは累計の差に限られます。

## 5. 検算

- 自己検査(スクリプト内): 損税削減=税率部分+課税化部分、ΔT_base=課税売上税額−控除額、公費+消費者=出力税、κ=0 で課税化部分=0、τF=τ0 で税率部分=0、開始年を遠方にすると ΔT_base=0。すべて通過。
- 手計算: 2040 年の損税削減 = 0.10×(14.5×1.015¹⁵=18.13)=1.813、ΔT_base=0.05×(88.77−18.13)=3.53(出力と一致)。医療 2038 年: R=54.61、P=10.92、L_SQ=1.092、ΔT_base=2.184(別計算と一致)。
