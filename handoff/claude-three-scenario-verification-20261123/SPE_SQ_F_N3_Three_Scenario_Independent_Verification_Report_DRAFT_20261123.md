## 3. 重点項目の結果

**SQ／F／N3の共通比較条件**
- SQ・F・N3は、初期値（実質580／名目600、暗黙デフレーター 600/580）、基調成長1%、労働弾性0.65、基調インフレ2%、イベント損失率とアンカー年の**パラメータが全て同一**。N3はSQと135共通キーが全て同一、Fは135キー中9キー（`governance_allocation`、`invoice_cost_saving`、`stamp_tax_removed`、`digital_system_cost`、`investment_flow_share`、`training_credit_rate`、`elderly_subsidy_per_worker_man`、`pension_relief_per_worker_man`、`education_bond_share`）だけが異なる。いずれも施策入力で、マクロ共通パラメータではない。
- N3内の固定SQ分母（別実行）とSQ再実行は、コア・Y・N・労働・消費・投資・資本・税が全30年で一致（300項目）。N3のコア差は全年0（政策は人口・労働・コアを動かさない）。

**実質・名目GDPとデフレーター**
- SQのコア実質 `Y_core=580×非労働係数×(L/L2026)^0.65`、名目コア `N_t=N_(t-1)×(1+g_t+π_t)`、`d=N/Y`、最終 `N=Y×d×(1+価格圧力)` を、私の式で全30年一致（残差0）。SQ・Fは価格圧力0（N3のみ0.5×未充足/コア）。F・N3も同じ式で一致。
- 入力インフレπと暗黙デフレーター成長は別物：加算式では `d`の成長率＝π/(1+g)。SQの暗黙デフレーターCAGRは2.182%、入力インフレ平均2.172%、名目CAGRは1.858%（原文§9の「名目年3%」より低い。実質CAGRが負のため）。**原式を保持しており、価格規約の変更はしていない**。
- 納品CSVの差分・比率・実質成長・`GDP_minus_2026_580`・SQ割れ年数（SQ 0／F 0／N3 26）・対580割れ年数（3者とも29）・主要年は私の値と一致。報告書の見出し表も6桁で一致。

**イベント適用**

**F医療参照接続**
- Fの共通医療定義（共通パラメータ・財源・臨床区分・登録基準）はN3と一致。Fの医療価格参照は、接続後はN3の医療初期化・SQのトレースと一致（旧Fは最大8.8e-5ずれ）。F再接続の効果は2055年に−9.4e-6兆円と極小。教育モジュールは固有デフレーターのままで、私が別に走らせた実験（教育にもSQ参照デフレーターを入れる）でも2055年の差は+5.0e-5兆円。**参照・分母の整合は数値的には無視できる**。旧SQ_FIXED→共通ON分母の差は−1.2e-4兆円。

## 4. 論点（優先順、5件）

1. **3者とも2055年まで初期580を下回る（SQも29年）**。私の算術分解では、SQの2055年コア＝580×非労働係数1.0496（基調成長と永続損失の合成）×労働係数0.8689（労働が2026年の80.6%へ）＝528.96兆円。減少は労働項に由来する。原因の診断は範囲外で、共通マクロの課題として次工程へ。
2. **N/Aと開示の読み方**：投資・家計・基金・国地方財政の比較不能列はN/Aで、順位は付けていない（確認済み）。N3のみにPB・債務があり、Fには補っていない。N3の「追加G/I OFF」は政府側のみ（上記）。
3. **原文に無い実装仮定が残る**：災害・気候の起点年（2029／2028）、回復なし、人口初期値122,618,024（§9は1億2150万人）、2026オイルの初期不適用。いずれも報告書が開示しているが、原文が定めるのは「3年毎」「隔年」「2026年ショック」まで。
4. **`SQ_common_macro_change_real`・`N3_common_macro_change_real`列は定数0の書き込み**（コードに直書き）。0であること自体は上記の独立比較で裏づけたが、列値は計算結果ではない。
5. **未検証の限界**：エンジン全体の独立再実装、人口・労働入力（デモグラフィ側）の原典照合、全国較正、F／N3の未較正パラメータの妥当性、`Ctarget`等の内部項。再実行の環境は私の3.13.17で、Workの実行環境は記録されていない。
