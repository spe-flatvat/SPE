## 4. GDP差の分解
- 2055年: LATEST_F − OLD_MEDICAL_F = −0.239、− OLD_EDUCATION_F = −0.164、− MEDICAL_OFF = −0.119（いずれも兆円）。医療修正（M-1〜M-5）による GDP 変化は −0.1〜−0.2 兆円規模で、F全体の +11.3 に比べ小さい。
- 付加価値換算率 0/50/100% × 財源対応 0/50/100% の 3×3 では、2055年 GDP は 540.197〜540.352（幅 0.155兆円）。LATEST_F は 540.274。感度は小さく、**医療のGDP結論（小さな負寄与）は仮定に対して頑健**。ただし VA率・輸入率・中間投入率は産業連関で較正されていない候補値。
- 2026→2027年の GDP 段差（580.0→555.3）は SQ_FIXED でも同じで、F起因ではなくベース年の特性。

## 5. 家計負担の感度

## 6. 指摘事項（N3前に直す／注記する）
1. **供給上限の二重利用（算術上は正しく再現されるが設計上の問題）**: `chosen_transitions` と `universal_palliative_served` がそれぞれ同じ `transition_capacity` で上限をかけられ、合算が上限を超える（LATEST_F で21年分、最大 1.62倍。例 2035年 12,474＋61,696 ＝ 74,171 ＞ 61,696）。上限を共有するなら合算で制限する必要がある。
2. **普遍的緩和ケアの患者負担が 0.9%**: 費用の約99%が公費・保険者負担になっている。請求ベースの限界自己負担として意図通りか要確認（Ownerの制度意図に依存）。
3. **`post_financing_transfer_residual_trn` は恒等的に0**（式が打ち消し合う）。会計の独立検査として機能していない。実質の検査は `medical_unassigned_direct_cash_requirement_trn`（2055年 −0.267兆円）側にある。
4. INVESTMENT チャネルの未接続（上記3）。限界効果表では「0」ではなく「未接続」と表示する方がよい。
