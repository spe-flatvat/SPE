### 2.3 再計算式

以下は共通標本・用途配賦・税率区分を揃えた後の計算手順であり、今回未取得額を埋めた全国計算ではない。

```text
病院の課税対象経常費用候補
  = 課税対象材料購入額（費消額から在庫増減を調整）
  + 通常必要な国内通勤手当 + 課税委託費
  + 課税対象設備関係費（設備機器賃借料を除く） + 設備機器賃借料
  + 課税対象経費 + 課税対象その他医業・介護費用

P_net = Σ_r [経常課税購入gross_r/(1+r)] + Σ_r 経常課税購入net_r
      + 当期課税資産取得net
      （同一支出はgross又はnetの片側だけに含める）
input_VAT = Σ_r r × 購入・取得net_r
L_current = input_VATの対象非課税診療帰属分 − 現行制度で実際に控除される額
p_ratio = 対象非課税診療帰属P_net / 対応する対象売上R
```

減価償却、土地、非課税保険、通常給与を課税購入に含めない。取得費と償却、資産計上リースとその費用計上分、委託費と内訳再掲を重複計上しない。医療機関の介護・物販・自費・附属学校等の混在を用途配賦する。個別制度の課税分類は支出実態に依存する。

税率別仕入税額は未取得。8%対象と10%対象を分け、税抜額なら×r、税込額なら×r/(1+r)。食材購入と給食サービスを同じ税率と推定しない。一般病院投資314,618の全額税込10%なら28,601.636千円、全額税抜10%なら31,461.8千円という前回の感度例は維持できるが、全国観測税額ではない。
