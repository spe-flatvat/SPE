    05 / INTERPRETATION

    この計算で確認できる範囲

    計算関係

    実質成長 = 基調 + 消費 + 投資 + 教育 − risk + (1−α) × (人口成長 + aging drag)
    名目成長 = 実質成長 + 基調インフレ + 追加インフレ + VAT一時要因
    税収 = min(前年税収 × (1+名目成長×弾性) × イベント倍率, 名目GDP×30%)
    歳出 = 前年歳出 × (1+歳出成長率)
    資金不足proxy = max(歳出−税収, 0)

    イベントの式上の接続は確認できますが、反実仮想比較による実証的な因果効果を推定したものではありません。

    未算出・暫定仮定

    税率→税収基盤、医療・年金の制度別収支、所得分配、政策金利、配当、内部留保、労働者人口人数、非正規率、所得中央値、エンゲル、ジニの内生変化、実際の国債・債務・PBは評価できません。

    移民の線形刻み、賃金中間年、税収弾性の境界、α/φ、aging dragの組込みは仮定を含みます。v5の実質賃金初期値380とFアンカー400の相違は裁定せず、今回は既存計算の400を保持しています。
